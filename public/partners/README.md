# Logos des partenaires

Déposer ici les logos fournis (PNG transparent, WebP ou SVG), puis ajouter les
partenaires dans `src/data/partners.ts` : nom, chemin du logo et lien facultatif.
Conserver les couleurs et proportions originales des logos.

La section se trouve en bas de l'accueil et reste masquée lorsque la liste est
vide. Aucun partenaire fictif n'est affiché. L'ajout se fait dans les fichiers du
projet ; il n'y a pas d'interface d'administration pour les partenaires.
